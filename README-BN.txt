ANDROID UPLOAD STEPS
1. Extract this ZIP using My Files.
2. Open your GitHub repository in Chrome.
3. Switch Chrome to Desktop site if the upload controls are not visible.
4. Choose Add file > Upload files.
5. Select the seven files listed above from the extracted folder.
6. Commit changes to the main branch.
7. Wait for GitHub Pages to deploy, then refresh:
